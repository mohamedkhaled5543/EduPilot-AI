
# EduPilot AI

An AI-powered multi-agent educational platform for personalized learning, intelligent assessment, and student performance analytics.

## Project Overview

EduPilot AI connects students and instructors through an intelligent learning platform powered by AI.

## Core Features

- AI Learning Tutor with RAG and source citations
- AI-powered assessment generation
- Automated student assessment and grading
- Student performance analytics
- Personalized learning recommendations
- Instructor AI Assistant

## Initial Scope

The first release will support five fourth-year Computer Science courses.

## Technology Stack

- Frontend: Next.js, TypeScript
- Backend: Python, FastAPI
- Database: PostgreSQL, pgvector
- AI: LLMs, RAG, LangGraph
- Deployment: Docker

## Project Status

Currently in the initial setup and requirements phase.
